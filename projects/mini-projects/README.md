# 🎮 Mini Projects (Latihan Interaktif & Studi Kasus WPU)

Selamat datang di direktori **Mini Projects**! Kumpulan projek ini adalah implementasi praktis dari materi fundamental dan DOM interaktif (terinspirasi dari kurikulum studi kasus Web Programming UNPAS - WPU).

Projek-projek ini berfungsi sebagai jembatan yang menghubungkan teori dasar bahasa (perulangan, percabangan, array, object, DOM selection, DOM event) ke dalam program nyata yang interaktif dan menyenangkan.

---

## 📚 Daftar Mini Projects:

### 1. Logika & Fundamental Pemrograman (CLI & Console)

| No | Folder Projek | Topik Utama | Deskripsi Singkat |
| :---: | :--- | :--- | :--- |
| **01** | [`01-juragan-angkot`](./01-juragan-angkot/README.md) | Loops & Conditionals | Simulasi pengelolaan operasional 10 armada angkot bertingkat (angkot normal, rusak, dan lembur). |
| **02** | [`02-suit-jawa-cli`](./02-suit-jawa-cli/README.md) | Random Math & Branching | Game klasik Suit Jawa (Gajah, Orang, Semut) melawan komputer berbasis terminal / prompt dialog. |
| **03** | [`03-tebak-angka-cli`](./03-tebak-angka-cli/README.md) | Do-While & Number Range | Permainan menebak angka rahasia 1–10 dengan batas 3 kali kesempatan tebakan. |

### 2. Antarmuka Web Interaktif (DOM Manipulation & Events)

| No | Folder Projek | Topik Utama | Deskripsi Singkat |

## 🛠️ Cara Menjalankan

### A. Menjalankan Projek CLI (Node.js Terminal)
```bash
# Menjalankan simulasi angkot:
node projects/mini-projects/01-juragan-angkot/example.js

# Menjalankan suit jawa CLI:
node projects/mini-projects/02-suit-jawa-cli/example.js

# Menjalankan tebak angka CLI:
node projects/mini-projects/03-tebak-angka-cli/example.js
```

### B. Menjalankan Projek GUI (Browser)
Buka file `index.html` pada masing-masing sub-folder langsung di browser Anda, atau gunakan ekstensi **Live Server** di VS Code:
- `projects/mini-projects/04-color-picker/index-1.html`
- `projects/mini-projects/05-suit-jawa-gui/index.html`
- `projects/mini-projects/06-image-gallery/index.html`
