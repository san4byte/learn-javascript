# 06 - DOM Traversal dan Event Bubbling

## Tujuan Belajar
- Menelusuri hubungan antar node (`parentElement`, `nextElementSibling`, dll.).
- Memahami konsep *Event Bubbling*.
- Menggunakan `e.stopPropagation()` dan `e.preventDefault()`.

## Penjelasan Konsep
DOM Traversal adalah cara bernavigasi dari satu elemen ke elemen kerabatnya. Event Bubbling adalah fenomena di mana event yang terjadi pada elemen anak menjalar ke atas menuju elemen induknya.
