# 05 - DOM Events

## Tujuan Belajar
- Memahami cara kerja event handling pada JavaScript.
- Membandingkan Event Handler inline, properti onclick, dan `addEventListener()`.

## Penjelasan Konsep
Event adalah kejadian yang terjadi pada halaman web (seperti klik mouse, tombol ditekan, scroll). `addEventListener()` adalah metode standar yang fleksibel karena memungkinkan pendaftaran lebih dari satu listener pada elemen yang sama.
