# 09 - Latihan Galeri Gambar Interaktif

## Tujuan Belajar
- Memahami teknik *Event Delegation* pada kumpulan thumbnail.
- Mengubah atribut `src` gambar utama secara dinamis.

## Penjelasan Konsep
Alih-alih memberi listener ke tiap gambar thumbnail, event listener dipasang pada container induknya (*event delegation*).
