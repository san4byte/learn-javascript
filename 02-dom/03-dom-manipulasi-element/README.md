# 03 - DOM Manipulasi Element

## Tujuan Belajar
- Mengubah isi elemen HTML (`innerHTML`, `textContent`).
- Memanipulasi CSS inline style melalui properti `style`.
- Mengelola atribut elemen (`setAttribute`, `getAttribute`, `removeAttribute`, `classList`).

## Penjelasan Konsep
Manipulasi element berfokus pada pengubahan konten visual, atribut, dan kelas CSS pada elemen yang sudah ada di halaman web.
