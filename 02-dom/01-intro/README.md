# 01 - Pengenalan DOM (Document Object Model)

## Tujuan Belajar
- Memahami apa itu Document Object Model (DOM).
- Mengetahui struktur hierarki DOM Tree.
- Memahami hubungan antara HTML, Browser, dan JavaScript.

## Penjelasan Konsep
DOM adalah antarmuka pemrograman untuk dokumen HTML dan XML. DOM merepresentasikan dokumen web sebagai pohon node (*tree of nodes*), di mana setiap elemen, atribut, dan teks adalah sebuah objek yang dapat dimanipulasi dengan JavaScript.
