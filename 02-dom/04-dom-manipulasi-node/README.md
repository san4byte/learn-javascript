# 04 - DOM Manipulasi Node

## Tujuan Belajar
- Membuat elemen baru (`createElement`, `createTextNode`).
- Memasukkan elemen ke dokumen (`appendChild`, `insertBefore`).
- Menghapus dan mengganti elemen (`removeChild`, `replaceChild`).

## Penjelasan Konsep
Manipulasi node memungkinkan penambahan atau penghapusan elemen secara dinamis dari pohon DOM.
