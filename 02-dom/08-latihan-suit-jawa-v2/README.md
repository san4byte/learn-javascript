# 08 - Latihan Game Suit Jawa v2.0 (GUI Interaktif)

## Tujuan Belajar
- Mengembangkan game berbasis grafis visual dengan gambar interaktif.
- Membuat efek animasi acak bergulir (*rolling animation*) menggunakan `setInterval()`.
- Menampilkan skor dan hasil pertandingan langsung di antarmuka DOM.

## Penjelasan Konsep
Pengguna memilih gajah, orang, atau semut dengan mengklik gambar. Sebelum hasil diumumkan, fungsi `putar()` mengacak gambar komputer berulang-ulang selama 1 detik menggunakan `setInterval` dan `clearInterval`, memberikan pengalaman bermain yang interaktif.

Tinjau implementasi di [contoh.js](contoh.js).
