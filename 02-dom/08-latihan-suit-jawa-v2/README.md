# 08 - Latihan Game Suit Jawa v2.0 (GUI)

## Tujuan Belajar
- Mengintegrasikan antarmuka grafis dengan logika game.
- Mengimplementasikan animasi putar dengan `setInterval()` sebelum menampilkan pemenang.

## Penjelasan Konsep
Game Suit Jawa yang sebelumnya berbasis alert/prompt diubah menjadi antarmuka visual dengan gambar animasi jempol, telunjuk, dan kelingking.
