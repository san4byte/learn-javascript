# 02 - DOM Selection

## Tujuan Belajar
- Memahami perbedaan method seleksi DOM.
- Mengetahui perbedaan nilai kembalian: Element, HTMLCollection, dan NodeList.

## Penjelasan Konsep
1. `getElementById()` -> mengembalikan 1 Element tunggal.
2. `getElementsByTagName()` -> mengembalikan `HTMLCollection`.
3. `getElementsByClassName()` -> mengembalikan `HTMLCollection`.
4. `querySelector()` -> mengembalikan 1 Element pertama yang cocok dengan CSS selector.
5. `querySelectorAll()` -> mengembalikan `NodeList`.
