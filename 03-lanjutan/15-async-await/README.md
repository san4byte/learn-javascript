# 15 - Async / Await & Error Handling

## Tujuan Belajar
- Menulis kode asinkron dengan gaya penulisan sinkron yang rapi.
- Menggunakan keyword `async` dan `await`.
- Menangani error secara tangguh menggunakan blok `try...catch` dan validasi status HTTP.

## Penjelasan Konsep
`async/await` adalah fitur di atas Promise yang menyederhanakan penulisan kode asinkron agar alur program lebih mudah dibaca dan di-debug.
