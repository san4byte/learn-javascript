# 05 - Template Literals dan Tagged Templates

## Tujuan Belajar
- Menggunakan backtick untuk string interpolation (`${expression}`).
- Membuat template HTML multi-line.
- Memahami konsep advance *Tagged Template Literals*.

## Penjelasan Konsep
Template literals menggantikan penggabungan string dengan tanda tambah (`+`), mendukung ekspresi matematika, pemanggilan fungsi, dan parsing string khusus via Tagged Templates.
