# 09 - Rest Parameter (`...`)

## Tujuan Belajar
- Menangkap sisa argumen fungsi menjadi sebuah array asli.
- Menggantikan keterbatasan `arguments` object semu.
- Mengombinasikan rest parameter dengan destructuring assignment.

## Penjelasan Konsep
Rest parameter mengumpulkan sisa argumen menjadi array sejati, ditempatkan di akhir daftar parameter fungsi.
