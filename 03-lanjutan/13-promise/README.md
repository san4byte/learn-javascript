# 13 - Promise

## Tujuan Belajar
- Memahami objek Promise sebagai solusi callback hell.
- Mengetahui 3 status Promise: *Pending*, *Fulfilled*, *Rejected*.
- Menggunakan method `.then()`, `.catch()`, dan `.finally()`.

## Penjelasan Konsep
Promise adalah objek yang mewakili penyelesaian atau kegagalan dari sebuah operasi asinkron di masa mendatang.
