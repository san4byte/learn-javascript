# 08 - Spread Operator (`...`)

## Tujuan Belajar
- Memecah (*expand*) iterable menjadi elemen-elemen individual.
- Menggabungkan dua atau lebih array.
- Menyalin (*copy*) array secara aman tanpa mereferensikan memori yang sama.

## Penjelasan Konsep
Spread operator (`...`) memungkinkan ekspansi elemen iterable ke tempat yang membutuhkan argumen atau elemen list.
