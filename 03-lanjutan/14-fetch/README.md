# 14 - Fetch API

## Tujuan Belajar
- Mengambil data dari web service menggunakan Fetch API standar tanpa dependensi luar.
- Memahami parsing respons JSON (`response.json()`).
- Menampilkan data hasil fetch ke antarmuka DOM secara dinamis.

## Penjelasan Konsep
Fetch API adalah standar browser modern pengganti XMLHttpRequest berbasis Promise untuk komunikasi HTTP.
