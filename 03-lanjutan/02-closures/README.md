# 02 - Closures dan Lexical Scoping

## Tujuan Belajar
- Memahami konsep Lexical Scope.
- Memahami bagaimana closure mempertahankan akses ke variabel lokal induknya.
- Menerapkan closure untuk *factory function* dan *private variable*.

## Penjelasan Konsep
Closure adalah kombinasi antara sebuah fungsi dan lingkungan leksikal di mana fungsi tersebut dideklarasikan, memungkinkan fungsi mengingat data lingkungan luar meskipun fungsi luar telah selesai dieksekusi.
