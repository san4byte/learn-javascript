# 11 - Timing Events: setTimeout dan setInterval

## Tujuan Belajar
- Menjalankan kode terjeda dengan `setTimeout()`.
- Menjalankan kode berulang pada interval tertentu dengan `setInterval()`.
- Menghentikan timer menggunakan `clearTimeout()` dan `clearInterval()`.

## Penjelasan Konsep
Timing events adalah API bawaan browser untuk menjadwalkan eksekusi fungsi di masa mendatang.
