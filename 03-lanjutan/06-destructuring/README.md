# 06 - Destructuring Assignment

## Tujuan Belajar
- Membongkar elemen array dan properti objek ke dalam variabel terpisah.
- Menetapkan nilai default (*default values*).
- Menukar nilai variabel (*swap*) tanpa variabel sementara.

## Penjelasan Konsep
Destructuring adalah ekspresi JavaScript yang memungkinkan ekstraksi data dari array atau objek ke variabel yang berbeda secara ringkas.
