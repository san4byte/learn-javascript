# 01 - Object Lanjutan (Prototype & Class)

## Tujuan Belajar
- Memahami efisiensi memori dengan `Object.create()`.
- Memahami konsep Prototype Inheritance di JavaScript.
- Menguasai sintaks ES6 `class`.

## Penjelasan Konsep
Sebelum ES6 class diperkenalkan, inheritance di JavaScript dibangun di atas prototype inheritance. Keyword `class` pada dasarnya adalah *syntactic sugar* di atas sistem prototype tersebut.
