# 04 - Higher-Order Functions (Filter, Map, Reduce)

## Tujuan Belajar
- Memahami konsep fungsi yang menerima atau mengembalikan fungsi lain.
- Menggunakan method deklaratif `filter()`, `map()`, dan `reduce()`.
- Menerapkan method chaining untuk pengolahan data array.

## Penjelasan Konsep
Higher-order functions memungkinkan penulisan kode fungsional yang deklaratif, bersih, dan mudah di-maintain dibanding loop manual.
