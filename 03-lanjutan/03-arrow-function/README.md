# 03 - Arrow Function

## Tujuan Belajar
- Menguasai sintaks modern Arrow Function (`=>`).
- Memahami *implicit return* pada one-liner function.
- Mengetahui perbedaan konteks `this` pada arrow function (lexical `this`).

## Penjelasan Konsep
Arrow function menyediakan sintaks ringkas dan tidak memiliki binding `this` sendiri (mengambil `this` dari cakupan leksikal di sekelilingnya).
