# 07 - Perulangan Modern: For..of dan For..in

## Tujuan Belajar
- Membedakan perulangan `for..of` dan `for..in`.
- Melakukan iterasi pada struktur data *iterable* (Array, String, NodeList, arguments).
- Melakukan enumerasi pada properti objek.

## Penjelasan Konsep
- `for..of`: Mengiterasi **nilai** dari objek iterable (Array, String, NodeList).
- `for..in`: Mengiterasi **properti / key** dari sebuah objek.
