# 07.2 - Project Pengelolaan Penumpang Angkot

## Tujuan Belajar
- Menerapkan manipulasi array untuk simulasi kursi penumpang angkot.
- Menangani logika kursi kosong (`undefined`), penumpang ganda, dan penumpang turun.

## Contoh Kode
```javascript
let penumpang = [];
function tambahPenumpang(nama, list) { ... }
function hapusPenumpang(nama, list) { ... }
```

### Output
Array penumpang terisi dan terkelola sesuai kapasitas angkot.
