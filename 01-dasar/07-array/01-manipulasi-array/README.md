# 07.1 - Manipulasi Array

## Tujuan Belajar
- Memahami struktur array dan indeks berbasis nol.
- Menguasai method dasar array: `push`, `pop`, `shift`, `unshift`, `splice`, `slice`, `join`, `forEach`.

## Penjelasan Konsep
Array adalah tipe data yang dapat menampung sekumpulan nilai dari berbagai tipe data secara berurutan. Manipulasi array meliputi penambahan, penghapusan, dan iterasi elemen.

## Contoh Kode
```javascript
let arr = ["agus", "rehan", "samsul"];
arr.push("lutfi", "roy"); // Menambah di akhir
arr.pop(); // Menghapus elemen terakhir

console.log(arr);
```

### Output
`[ 'agus', 'rehan', 'samsul', 'lutfi' ]`
