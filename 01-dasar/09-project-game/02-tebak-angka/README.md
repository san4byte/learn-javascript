# 09.2 - Game Tebak Angka

## Tujuan Belajar
- Menggunakan counter kesempatan dan perulangan `while`.
- Memberikan petunjuk logika (terlalu tinggi / terlalu rendah).

## Penjelasan Konsep
Komputer membangkitkan angka acak 1–10. Pemain diberi 3 kali kesempatan untuk menebak dengan petunjuk apakah tebakan terlalu besar atau terlalu kecil.
