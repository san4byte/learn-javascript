# 09.1 - Game Suit Jawa

## Tujuan Belajar
- Menerapkan logika percabangan, angka acak (`Math.random()`), dan interaksi pengguna.
- Merefaktorisasi kode prosedural menjadi modular berbasis fungsi.

## Penjelasan Konsep
Aturan Suit Jawa:
- Gajah menang melawan Orang, kalah dari Semut.
- Orang menang melawan Semut, kalah dari Gajah.
- Semut menang melawan Gajah, kalah dari Orang.
Komputer memilih secara acak melalui `Math.random()`.
