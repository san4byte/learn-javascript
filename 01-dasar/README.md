# 📘 Modul 01: JavaScript Dasar & Modern ES6+

Selamat datang di **Modul 01**! Modul ini adalah fondasi terlengkap untuk menguasai logika pemrograman dan sintaks modern JavaScript. Di modul ini, fitur-fitur modern ES6+ (seperti Template Literals, Arrow Function, Destructuring, Spread, Rest Parameter, Closures, dan HOF) telah diintegrasikan langsung bersama topik dasarnya.
