# 08.4 - Latihan Pengelolaan Angkot dengan Object

## Tujuan Belajar
- Mengintegrasikan OOP dasar ke dalam simulasi angkot.
- Menyimpan supir, trayek, kas, dan daftar penumpang di dalam objek.

## Penjelasan Konsep
Membuat constructor `Angkot(sopir, trayek, penumpang, kas)` dengan method `penumpangNaik(namaPenumpang)` dan `penumpangTurun(namaPenumpang, bayar)`.
