# 📘 Modul 01: JavaScript Fundamentals & Modern ES6+

Selamat datang di **Modul 01**! Modul ini adalah dokumentasi fondasi terlengkap untuk menguasai logika pemrograman dan sintaks modern JavaScript, mulai dari dasar bahasa hingga fitur modern ES6+ dan spesifikasi ECMAScript terkini.

---

## 📚 Daftar Materi Pembelajaran

1. [01 - Popup Boxes (alert, prompt, confirm)](01-popup-boxes/README.md)
   - Kotak dialog interaktif modal dan sifat blocking di browser.
2. [02 - Variables and Scope (var, let, const, Hoisting & TDZ)](02-variables-and-scope/README.md)
   - Block scope vs function scope, fenomena hoisting, dan diagram Temporal Dead Zone.
3. [03 - Template Literals & String Interpolation](03-template-literals/README.md)
   - String interpolasi `${...}`, teks multi-line natural, dan tagged templates.
4. [04 - Loops (While, Do-While, For, Nested Loops, For..of & For..in)](04-loops/README.md)
   - Perulangan terhitung, evaluasi kondisi, traversal matriks 2D, dan iterasi iterable vs objek.
5. [05 - Conditionals (If Else, Switch Case, Ternary)](05-conditionals/README.md)
   - Seleksi kondisi, evaluasi truthy/falsy, short-circuit logic, dan pola Object Lookup Table.
6. [06 - Functions (Deklarasi, Scope, Closures, Arrow Functions, HOF, Rest, Rekursif)](06-functions/README.md)
   - Parameter default, lexical scope chain, data privacy dengan closure, HOF array, dan dekomposisi masalah.
7. [07 - Arrays (Manipulasi, Mutator & Accessor, Destructuring, Spread)](07-arrays/README.md)
   - Operasi stack/queue, perbedaan mutlak slice vs splice, destructuring, swap, dan kloning spread.
8. [08 - Objects (Literal, This, Methods, Destructuring, Prototype)](08-objects/README.md)
   - Tiga cara pembuatan objek, binding kata kunci this, destructuring bertingkat, dan prototype memory sharing.
9. [09 - Tipe Data Lanjutan, Operator in, typeof, dan Falsy Truthy](09-data-types-and-operators/README.md)
   - 8 tipe data ECMAScript, semantik null vs undefined, operator in, typeof quirk, dan evaluasi boolean.
10. [10 - Sintaks Modern ES Lanjutan (Optional Chaining, Nullish Coalescing, Strict Mode)](10-advanced-syntax/README.md)
    - Optional Chaining (`?.`), Nullish Coalescing (`??`), logical assignments, dan proteksi Strict Mode.

---

## 🛠️ Cara Menjalankan

Seluruh materi di bab ini dapat dijalankan langsung di terminal menggunakan Node.js:

```bash
node 01-fundamentals/04-loops/example.js
node 01-fundamentals/06-functions/example.js
node 01-fundamentals/07-arrays/example.js
node 01-fundamentals/08-objects/example.js
node 01-fundamentals/09-data-types-and-operators/example.js
node 01-fundamentals/10-advanced-syntax/example.js
```
