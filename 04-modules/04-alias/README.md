# 04 - Alias (as)

## Tujuan Belajar
- Menggunakan kata kunci `as` untuk memberi nama alias pada proses export maupun import.
- Menghindari konflik penamaan ketika mengimpor dua module yang memiliki nama fungsi serupa.
