# 02 - Export dan Import

## Tujuan Belajar
- Mengetahui cara mengekspor fungsi dan konstanta dengan keyword `export`.
- Mengimpor komponen module menggunakan keyword `import { ... }`.
- Memahami atribut `type="module"` pada tag `<script>`.

## Penjelasan Konsep
1. **`export`**: Menandai fungsi, variabel, atau class agar bisa diakses oleh file JavaScript lain.
2. **`import`**: Mengambil komponen yang telah diekspor dari module lain.
3. **`type="module"`**: Memberi tahu browser bahwa file tersebut adalah ES Module sehingga browser mengisolasi scope dan mendukung sintaks `import`/`export`.
