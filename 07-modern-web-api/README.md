# 🌐 Modul 07: Modern Web API & Real-World JavaScript Essentials

Selamat datang di **Modul 07**! Modul ini dirancang khusus untuk menjembatani teori JavaScript dasar & OOP dengan **kebutuhan nyata di industri perangkat lunak modern**.

Topik-topik di modul ini adalah pola dan Web API yang **paling sering digunakan setiap hari** oleh frontend dan fullstack developer saat membangun aplikasi web seperti dashboard, toko online e-commerce, hingga portal berita.

---

## 📚 Daftar Materi Pembelajaran:

1. [01 - Web Storage API (localStorage, sessionStorage, Cookies)](01-web-storage/README.md)
   - Penyimpanan data permanen dan temporer di browser, token auth (JWT), preferensi Dark/Light mode, dan keamanan data klien.
2. [02 - Modern Syntax ES2020-ES2023](02-modern-syntax-es2020/README.md)
   - _Optional Chaining_ (`?.`), _Nullish Coalescing_ (`??`), _Deep Clone_ (`structuredClone`), dan _Immutable Array Methods_ (`toSorted`, `toReversed`).
3. [03 - URL, URLSearchParams, dan FormData API](03-url-and-formdata/README.md)
   - Manipulasi filter/pencarian URL yang dapat dibagikan (_shareable links_) serta penanganan form input dan upload file gambar/dokumen.
4. [04 - Asynchronous Paralel & AbortController](04-async-parallel-abort/README.md)
   - Eksekusi banyak API secara serentak (`Promise.all`, `Promise.allSettled`) dan membatalkan HTTP fetch agar tidak terjadi _race condition_.
5. [05 - Optimasi Performa Event (Debounce & Throttle)](05-debounce-and-throttle/README.md)
   - Mengendalikan event berfrekuensi tinggi (_event flooding_) pada form live search, window resize, dan infinite scroll.
6. [06 - Intersection Observer API](06-intersection-observer/README.md)
   - Standar modern industri untuk _Lazy Loading_ gambar dan _Infinite Scroll_ yang sangat hemat memori dan ramah performa CPU.

---

## 🛠️ Cara Menjalankan Kode

- Materi non-visual dapat dijalankan di Node.js: `node 07-modern-web-api/02-modern-syntax-es2020/example.js`
- Materi visual (Web Storage, Debounce, Observer) dibuka lewat file `index.html` di browser menggunakan Live Server.
