# 🌐 Modul 07: Modern Web API & Real-World JavaScript Essentials

Selamat datang di **Modul 07**! Modul ini dirancang khusus untuk menguasai Web API browser standar industri yang **paling sering digunakan setiap hari** oleh frontend dan fullstack developer saat membangun aplikasi web modern (dashboard, e-commerce, hingga portal interaktif).

---

## 📚 Daftar Materi Pembelajaran:

1. [01 - Web Storage API (localStorage, sessionStorage, Cookies)](01-web-storage/README.md)
   - Penyimpanan data permanen dan temporer di browser, token auth, preferensi Dark/Light mode, dan keamanan data klien.
2. [02 - URL, URLSearchParams, dan FormData API](02-url-and-formdata/README.md)
   - Manipulasi parameter pencarian URL yang dapat dibagikan (_shareable links_) serta penanganan form input dan pengiriman data formulir.
3. [03 - Asynchronous Paralel & AbortController](03-async-parallel-abort/README.md)
   - Eksekusi request API secara serentak (`Promise.all`, `Promise.allSettled`) dan membatalkan HTTP fetch untuk mencegah _race condition_.
4. [04 - Optimasi Performa Event (Debounce & Throttle)](04-debounce-and-throttle/README.md)
   - Mengendalikan event berfrekuensi tinggi (_event flooding_) pada live search, window resize, dan scroll monitor.
5. [05 - Intersection Observer API](05-intersection-observer/README.md)
   - Standar modern industri untuk _Lazy Loading_ gambar dan _Infinite Scroll_ yang hemat memori dan ramah performa CPU.

---

## 🛠️ Cara Menjalankan Kode

- Seluruh materi di modul ini melibatkan API browser, sehingga dapat dijalankan dengan membuka berkas `index.html` pada masing-masing folder materi langsung di browser atau menggunakan ekstensi **Live Server** di VS Code.
- Materi komputasi non-DOM juga dapat dijalankan via Node.js:
  ```bash
  node 07-modern-web-api/02-url-and-formdata/example.js
  ```
