# 🎨 Modul 05: JavaScript DOM (Document Object Model)

Selamat datang di **Modul 05**! Document Object Model (DOM) adalah jembatan yang menghubungkan kode JavaScript dengan dokumen HTML di browser. Modul ini menyajikan konsep hierarki elemen, seleksi, manipulasi, traversal, hingga penanganan event pengguna.

---

## 📚 Daftar Materi Pembelajaran:

1. [01 - Pengenalan DOM & DOM Tree](01-intro/README.md)
   - Konsep dasar antarmuka W3C, struktur hierarki pohon dokumen, dan 4 tipe node utama.
2. [02 - DOM Selection](02-dom-selection/README.md)
   - 5 method seleksi elemen, perbedaan Single Element vs HTMLCollection vs NodeList.
3. [03 - DOM Manipulasi Element](03-element-manipulation/README.md)
   - Manipulasi teks aman (`textContent` vs `innerHTML`), atribut, dan manipulasi class CSS via `classList`.
4. [04 - DOM Manipulasi Node](04-node-manipulation/README.md)
   - Membuat dan menyisipkan elemen dinamis (`createElement`, `appendChild`, `prepend`, `insertBefore`).
5. [05 - DOM Events](05-dom-events/README.md)
   - Merespon aksi klik dan keyboard pengguna menggunakan `addEventListener()` dan event object `e`.
6. [06 - DOM Traversal dan Event Delegation](06-dom-traversal/README.md)
   - Menelusuri silsilah elemen, fenomena event bubbling, dan teknik optimasi performa _Event Delegation_.
7. [07 - HTML Form Elements](07-html-form-elements/README.md)
   - Mengambil nilai input (`input.value`), validasi form, dan mencegah refresh browser via `event.preventDefault()`.
8. [08 - HTML Table Elements](08-html-table-elements/README.md)
   - Manipulasi baris dan sel tabel secara terstruktur dengan method bawaan `insertRow()` dan `insertCell()`.
