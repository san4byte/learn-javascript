# 09 - Web Workers (Multi-Threading di Browser)

## Tujuan Belajar
- Memahami bahwa JavaScript secara default berjalan pada *Single Thread*.
- Menggunakan **Web Workers** untuk memproses komputasi CPU intensif di background thread.
- Berkomunikasi antar-thread menggunakan `postMessage()` dan `onmessage`.
- Mencegah UI browser mengalami *freeze* / *unresponsive* saat kalkulasi berat.
