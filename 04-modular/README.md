# 04 - JavaScript Modular (Webpack & Build Tools)

## Tujuan Belajar
- Memahami konsep modularitas dan pemisahan dependensi.
- Mengonfigurasi Webpack 5 untuk development dan production.
- Memahami Loaders (SCSS/CSS, HTML, Images) dan Plugins optimasi kode.

## Penjelasan Konsep
Modul memungkinkan pembagian aplikasi besar ke file-file kecil yang terisolasi. Webpack mengumpulkan modul-modul tersebut menjadi bundle aset yang optimal untuk browser.
